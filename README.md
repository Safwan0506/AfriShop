# AfriShop

## Description

AfriShop est un site vitrine pour une boutique de produits africains. Il comporte une page d'accueil, un menu de navigation, un catalogue de trois produits et une section contact.

## Auteur

Safwan Djazouli

## Technologies

- HTML5
- CSS3 (Flexbox)
- Git et GitHub pour le versionnage

## Instructions de lancement

1. Cloner le dépôt :

   ```
   git clone https://github.com/Safwan0506/AfriShop.git
   ```

2. Ouvrir le dossier `AfriShop`.
3. Ouvrir le fichier `index.html` dans un navigateur (double-clic, ou clic droit puis « Ouvrir avec »).

Aucune installation n'est nécessaire.
